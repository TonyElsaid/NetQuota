# Changelog

## 1.0.0
- Live per-app download/upload speeds with a 60-second graph
- Per-app daily and monthly totals stored in a local SQLite database
- Pause/resume network access per app using Windows Firewall rules
- Daily/monthly per-app quotas with automatic blocking and automatic reset
- Usage history window with a 30-day chart
- Optional VirusTotal scanning (hash lookup by default, upload only on request)
- One-file launcher (`NetQuota.bat`) that sets up Python dependencies
